# prompts 目录说明

Prompt 模板是本仓库的核心资产，用于把 AI 从“信息生成器”变成“决策辅助器”。

## 使用规则

1. 先选模板（按触发场景）。
2. 再填背景（由你提供事实与假设，不让 AI 编造）。
3. 最后才向 AI 提问，并要求按模板强制结构输出。

## 触发条件与使用规则

- `company-deep-dive.md`：只在你要验证/证伪单一公司假设时使用。
- `macro-trigger.md`：只在宏观出现明确事件时使用（利率决议、关键数据、政策变化）。
- `industry-shift.md`：只在行业出现拐点信号时使用。
- `risk-check.md`：用于持仓定期体检与风控动作判断。

## 禁止事项

- 禁止使用“帮我分析一下 XX 公司”这类开放式问题。
- 禁止让 AI 自己补背景、自己设问题。
- 禁止不按模板结构输出。
